# Project-GMTK-2026
Game Jam submission for the GMTK 2026 Game Jam

[![Unity CI and staging](https://github.com/Rounless-Studios/Project-GMTK-2026/actions/workflows/unity-ci.yml/badge.svg?branch=main)](https://github.com/Rounless-Studios/Project-GMTK-2026/actions/workflows/unity-ci.yml)

## CI/CD

Pull requests are validated with Unity tests and a WebGL smoke build. Every successful push to `main` builds Windows and WebGL and deploys the staging itch channels. Production is a manually approved, versioned release. See [docs/CI-CD.md](docs/CI-CD.md) for setup, operation, troubleshooting, rollback, and the GMTK deadline checklist.
